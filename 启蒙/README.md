# 《启蒙》

此目录用于承接你过去 10 年关于自身与世界之间认知、探索、感悟、创意、未竟心愿与项目构想的长期语料。

当前状态：

- 该目录已被正式命名为 `启蒙`
- 本仓库内尚未放入那 6000+ 篇原始内容
- 后续应以此作为《启蒙》的文件系统根目录或挂载入口

建议的首层分布：

- `identity`：自我定义、价值观、核心信念
- `worldview`：世界理解、社会判断、文明观察
- `method`：方法论、学习法、认知工具
- `creation`：创意、项目、表达构想
- `dialogue`：关键对话与问答
- `profiling`：画像工坊与阶段校准
- `wishes`：未竟心愿与长期召唤
- `openbasaka`：系统设计与个人智能体演化

注意：

- 《启蒙》的默认保存原则是原文逐字保留
- 总结、Wiki、AAAK、路线图都只能作为派生层
- 创意、项目、对话进入《启蒙》前，应经过点击式归档确认
