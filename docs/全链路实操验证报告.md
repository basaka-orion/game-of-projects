## 链路 7：33 个工具执行链路

### 代码追踪
```
tools/index.ts — initBuiltinTools() 注册 39 个工具
```

### 逐工具验证结果

| Tier | 工具数 | 有真实执行器 | 仅 MCP 桥接 | Stub |
|------|--------|------------|------------|------|
| 1 核心 | 4 | 4 | 2 (web_search, web_extract) | 0 |
| 2 扩展 | 14 | 14 | 0 | 0 |
| 3 集成 | 15+6 | 21 | 10 (browser_*) | 0 |
| HA | 4 | 4 (disabled) | 0 | 0 |

**每一个工具都有真实的 executor 函数**。具体分布：

- **Electron IPC 执行器**（terminal, file_read, file_write, process, patch, search_files）：直接调用 `window.electronAPI` → 主进程执行
- **LLM 执行器**（vision_analyze, image_generate, delegate_task）：调用 `chatCompletion()` 真实 API
- **SQL 执行器**（todo, cronjob, session_search, memory, memory_search, knowledge_add, send_message）：直接操作 SQLite
- **浏览器 API 执行器**（tts）：Web Speech API
- **MCP 桥接执行器**（web_search, web_extract, browser_*）：需要 MCP 服务器运行
- **本地执行器**（clarify, code_execute, execute_code）：`new Function()` JS 沙箱

### ⚠️ 发现的问题
1. **ReAct 工具循环（tool-loop.ts）只能解析简单参数**：正则 `tool_call:skill_id(args)` 无法处理结构化参数。`knowledge_add` 需要 subject/predicate/object 三个参数，但 tool loop 把所有参数扁平为一个 prompt 字符串。
2. **本地技能执行器（executor.ts:165-170）是 echo stub**：不依赖 LLM 也不依赖 MCP 的技能（如 memory-palace, game-progression）只返回 `[技能名] 已处理: xxx` 而不执行真实逻辑。
3. **工具和技能是两套并行系统**：tool-loop.ts 只调用 `executeSkill`，不调用 `executeTool`。在 tools/index.ts 注册但不在 skills/registry.ts 注册的工具对聊天不可达。

### 结论：⚠️ **部分可用** — 所有工具本身有真实执行器，但 tool-loop 的参数解析和调度有限制

## 最终评定

### 真正令人震撼的部分

1. **10 层 Prompt 组装**：每次聊天都注入 Soul、记忆、Boss 画像、项目、技能，2500 token 预算动态裁剪 — 这是整个应用的灵魂
2. **Self-Nudge 自动学习**：一条对话结束后自动触发 3 个记忆系统填充（记忆宫殿 + Agent Memory + 知识图谱）— 应用在不知不觉中学习你
3. **Honcho 辩证建模**：不是简单地记录偏好，而是论点-反论点-综合的辩证过程来建模用户 — 这是真正的用户理解
4. **PRD 4 轮生成 + 6 专家审阅**：最少 8 次 LLM 调用生成 16 章完整 PRD — 相当于一个小型 AI 团队在干活
5. **技能自进化**：使用 → 追踪 → 检测 → LLM 优化 → 实际使用进化后的 Prompt — 闭环

### 需要修复的关键问题

1. **LLM 失败时写入假数据**（GhostWidget.tsx:153-182）：应该明确告知用户"评估失败"而非用随机数伪装成功
2. **本地技能执行器是 echo stub**（executor.ts:165-170）：memory-palace、game-progression 等技能实际不执行
3. **工具参数解析限制**（tool-loop.ts）：无法处理结构化参数，限制了工具调用的丰富度

### 一句话总结

> **这不是形如虚设的空壳 — 这是一个有着完整数据流、真实 LLM 调用、多层记忆系统的严肃应用。8/10 条核心链路完全可用，2 条部分可用。最令人印象深刻的是 10 层 Prompt 组装和 Self-Nudge 自动学习机制。**
