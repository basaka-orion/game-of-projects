# Openbasaka 功能模块全方位测试方案

## 目标

这份测试方案用于确认三个模块是否真的好用：

1. Openbasaka 实时新闻回答：不编、不旧、不乱，格式清楚。
2. 知识＋大佬：目录可改名，文件显示名可改名，标签会自动生成专题页。
3. 定时任务：能创建、能试跑、能记录日志，失败时能看见原因。

## 一、实时新闻回答测试

### 准备

- Brave Search Key 已配置。
- App 重启一次，确保 Electron main/preload 更新生效。

### 测试问题

依次问：

1. 今日有什么惊艳的 AI？
2. 这几天 AI 圈有什么值得关注的事？
3. 最近一周 OpenAI / Anthropic / DeepSeek 有什么新动态？

### 合格标准

- 回答顶部必须写检索日期和时间窗口。
- 每条事实后必须有来源编号，例如 `[S1]`。
- 不能把 2 月、3 月旧闻列成今天新闻。
- 如果来源不足，必须说“来源不足”，不能硬凑榜单。
- 格式应该能扫读：标题、事实、为什么重要、可信度/限制。

## 二、知识＋大佬测试

### 目录改名

1. 进入 `知识＋大佬`。
2. 选择一个文件项目目录。
3. 点击 `重命名目录`。
4. 输入新名字，例如 `启蒙/过去的笔记测试`。

合格标准：

- 左侧目录下拉里的名字会更新。
- 原目录下的来源仍然能打开。
- 页面/来源不会丢失。
- 这只是知识库内的显示目录，不会改动你电脑上的真实原文件。

### 文件显示名、目录、标签编辑

1. 打开任意来源。
2. 点击 `编辑`。
3. 修改：
   - 显示名
   - 项目目录
   - 标签，例如 `世界模型，AI新闻，启蒙测试`
4. 点击保存。

合格标准：

- 来源标题会更新。
- 来源会进入新的项目目录。
- 标签专题页会自动生成或更新。

### 标签专题页

1. 在搜索框搜索刚才的标签，例如 `世界模型`。
2. 找到 `标签：世界模型` 页面。
3. 打开它。

合格标准：

- 页面在 `知识标签` 目录下。
- 页面里列出关联 Wiki 页面和原始来源。
- 后续给更多内容打同一个标签时，这个专题页会继续更新。

## 三、定时任务测试

### 创建最小安全任务

1. 进入 `定时`。
2. 新建任务。
3. 类型选择 `自定义`。
4. 名称填写 `定时任务试跑 - 今日复盘`。
5. Prompt 填写：`用三句话总结今天 Openbasaka 应该关注什么。`
6. 频率先随便选一个，例如 `每 6 小时`。
7. 保存。

### 立即试跑

1. 在任务卡片上点击 `试跑`。
2. 等待完成。
3. 切到执行日志。

合格标准：

- 不需要等到 cron 到点。
- 日志里出现这次任务。
- 状态是 `OK` 或清楚显示错误原因。
- 如果 App 开着，会优先走渲染进程完整 Agent 能力；如果不可用，会 fallback 到主进程。

### 长期稳定性

连续观察 24 小时：

- 是否按设定时间执行。
- 是否有重复执行。
- 是否有失败日志。
- 是否生成了有价值的结果。

## 四、你需要配合的地方

1. 告诉我你最想自动化的 3 个固定任务。
2. 确认是否要推送到 Telegram。
3. 测试期间尽量保持 App 开着，电脑不要睡眠。
4. 每次觉得“不好用”的地方，直接告诉我具体卡在哪一步。

## 五、验收口径

一个功能不是“能跑”就算完成，而要满足：

- 你知道入口在哪里。
- 你知道下一步该点什么。
- 出错时你看得懂原因。
- 结果能回到知识库、记忆或项目推进里。
- 这个功能每周至少值得用一次。
